## Agent 创建方式修改
修改 Agent 的创建方式，大的设计方案调整，具体要求下：

1、 Agent 改成多例的，每次在管理后台创建Agent 时，在Spring IOC 容器动态注册对应的 ReActAgent Bean 对象，设置好它的系统提示词、模型、工具。
2.、现以前默认的ReactAgent 配置。
3、 删除DynamicAgentMiddleware 用不到了，前面动态创建 Agent 时已经决定了它的模型、工具、系统提示词。
4、 删除 Agent 流式对话时动态设置 AgentRuntimeConfig （系统提示词、模型、工具） 的代码，前面创建 Agent 时已经设置好了。
5、 管理后台手动删除 Agent 时同步销毁 IOC 容器中对应的 Agent。 
6、 重要：每日重启项目时，动态注册 agent_info 表中Agent 到 Spring 容器。
7、 流式对话选择一个Agent时，收到请求后直接从容器中找到对应的Agent进行对话。
8、页面UI渲染和业务逻辑代码尽量分开，少在UI层写后端处理逻辑。
